# AI voice agent readiness checklist

Before a business builds an AI voice agent for calls or bookings, settle these points. Skipping them is why many pilots stall.

1. **The job.** Pick one task the agent does first: appointment booking, order status, FAQs or lead capture. Write what a finished call looks like.
2. **The information it needs.** Opening hours, prices, policies, service lists, and where each fact is kept up to date.
3. **Language.** Which languages callers use. Test English and Hindi, and mixed speech, with real recordings of your callers.
4. **Hand-off.** When the agent passes a call to a person, who answers, and what the agent tells the caller meanwhile.
5. **Booking versus request.** Decide whether the agent confirms a booking or only records a request for staff to confirm. State this clearly to callers.
6. **Consent and records.** Tell callers they are speaking to an automated agent and how recordings are used. Check the rules that apply to your sector.
7. **Measurement.** Review a sample of calls each week: resolved, handed off, failed. Fix the top failure first.
